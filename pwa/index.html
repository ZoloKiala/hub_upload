How to use this app

      
    

    

      
1. Choose a repository type — Model, Dataset or Space.

      
2. Create a new repository or update an existing one in IWMIHQ.

      
3. Drag files or a folder, browse, or import from GitHub. Folder structure is kept.

      
4. Review the pre-flight checks and the auto-generated README.

      
5. Select “Upload to Hub”. Large files upload via git LFS automatically.

Install this app

      
    

    

      
Chrome or Edge on desktop: click the install icon at the right of the address bar,
        or open the browser menu and choose “Install Hub uploader”.

      
Safari on iPadOS/macOS: use Share → Add to Dock. Once installed, this app opens in
        its own window with no browser chrome, and works offline until you upload.
